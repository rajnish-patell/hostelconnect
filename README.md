# HostelConnect — Production-Ready Hostel Parent Video Call Platform

**HostelConnect** is a specialized, enterprise-grade B2B SaaS platform for residential schools, boarding schools, and student hostels where young children are not permitted to have personal smartphones. It turns designated hostel-owned shared tablets, laptops, or desktops into secure, child-safe calling kiosks connecting exclusively to verified parents/guardians.

---

## 🚀 Key Architectural Features

- **Child-Safe Tablet Kiosks (`/device`)**:
  - Activated via temporary one-time 6-character codes generated by hostel administrators.
  - Large touch-friendly student directory and verified contact picker.
  - No public web browsing, no arbitrary room creation, and zero social media risk.
- **Server-Authoritative Duration & Quota Control**:
  - Configurable call window (e.g. 15 or 20 minutes) and daily quota limits.
  - Server-backed timers enforce auto-termination and immutable duration logging.
- **Multi-Tenant Supabase PostgreSQL & RLS**:
  - Full Row-Level Security (RLS) ensuring strict isolation across hostels, rooms, students, and parents.
- **Real Razorpay Standard Checkout**:
  - Real HMAC-SHA256 signature verification server-side.
  - Webhook handler with idempotency table (`payment_events`) to prevent duplicate activations.
- **Transactional Resend Emails**:
  - Automated branded HTML emails for call invites, verification notifications, and payment receipts.
- **Encrypted Jitsi Meet Integration**:
  - Cryptographically unpredictable meeting room IDs.
  - Configurable for standard cloud `meet.jit.si` or private self-hosted Jitsi bridges (`JITSI_DOMAIN`).
- **Role-Based Access Control (RBAC)**:
  - `SUPER_ADMIN`, `HOSTEL_ADMIN`, `WARDEN`, `STAFF`, `PARENT`, `STUDENT`, `DEVICE_OPERATOR`.

## ⚙️ Environment Variables Setup

Copy `.env.example` to `.env.local`:

```bash
cp .env.example .env.local
```

Fill in your service credentials:

```env
# Application
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_APP_NAME=HostelConnect

# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# Resend (Email)
RESEND_API_KEY=re_your_api_key
RESEND_FROM_EMAIL=HostelConnect <notifications@yourdomain.com>

# Razorpay (Payments)
RAZORPAY_KEY_ID=rzp_test_your_key_id
RAZORPAY_KEY_SECRET=your_key_secret
RAZORPAY_WEBHOOK_SECRET=your_webhook_secret

# Jitsi Video
JITSI_DOMAIN=meet.jit.si

# Platform Security
APP_ENCRYPTION_KEY=32_byte_random_hex
ADMIN_BOOTSTRAP_SECRET=your_strong_bootstrap_secret
```

## 🗄️ Database Setup (Supabase)

1. Create a new Supabase project at [supabase.com](https://supabase.com).
2. Open the **SQL Editor** in your Supabase dashboard.
3. Run the migration scripts in order:
   - `supabase/migrations/000_schema.sql` (Creates all tables, enums, foreign keys, indexes)
   - `supabase/migrations/001_rls_policies.sql` (Enables Row-Level Security on all tables)
   - `supabase/migrations/002_functions_triggers.sql` (Auto profile sync on auth signup, duration calculator)
   - `supabase/migrations/003_seed.sql` (Default subscription plans and platform settings)

## 💳 Razorpay Setup & Webhooks

1. Sign up on the [Razorpay Dashboard](https://dashboard.razorpay.com/) and obtain your **Key ID** and **Key Secret** (Test mode initially).
2. Navigate to **Settings > Webhooks > Add New Webhook**.
3. Set the Webhook URL:
   ```
   https://yourdomain.com/api/webhooks/razorpay
   ```
4. Set your **Secret** in `RAZORPAY_WEBHOOK_SECRET`.
5. Select active events: `order.paid`, `payment.captured`, `payment.failed`.

---

## 📧 Resend Email Setup

1. Sign up on [resend.com](https://resend.com) and create an API Key.
2. Under **Domains**, add and verify your sending domain (DNS TXT/MX records).
3. Set `RESEND_API_KEY` and `RESEND_FROM_EMAIL` in `.env.local`.

## 🖥️ Running Locally & Testing

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run automated unit tests**:
   ```bash
   npm test
   ```

3. **Start Next.js development server**:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🚀 Production Deployment (Vercel)

1. Push your repository to GitHub / GitLab.
2. Import the repository in [Vercel](https://vercel.com).
3. Add all environment variables from `.env.example` in Vercel project settings.
4. Deploy with standard Next.js build settings.
5. In Supabase Auth settings, set **Site URL** and **Redirect URLs** to your production domain (e.g. `https://yourdomain.com/callback`).
